Status: a reconstruction, not a prediction

The slip velocity that enters the model was measured in the same driven simulation that supplies the reference points. The comparison therefore shows how well this model form, with these inputs, reconstructs that one run. It does not test a prediction.

Three reports are kept apart:

  1. Numerical verification. Does the code solve the stated equations? Pass or fail.
  2. Source-curve reproduction. With the parameters read from the source paper, does the code return the model curves and flow rates that the paper plots? Pass or fail, within the extraction uncertainty.
  3. Agreement with molecular dynamics. The differences between the model and the published simulation points. Reported as numbers, without a verdict.

No case is called a qualified prediction until two things exist: an accuracy requirement written down for a stated use, and a test of the model against it with inputs obtained independently of the reference run, on a condition that was not used to choose those inputs. No published case provides such a condition yet.

Evidence labels on this page: Reconstruction, the inputs were measured in the same driven run as the reference. Equilibrium-input comparison, the inputs come from equilibrium simulations and are compared with driven runs; no such case is enabled yet.

Model and equations

Flow in the tube

Steady, fully developed flow of a Newtonian liquid with one viscosity μ in a cylinder of radius R, driven by a pressure gradient G. Two forms of the source paper are enabled for this case.

ModelVelocity profileFlow rate
Classical, no slip (Eqs. 1–2)u(r) = (R²G/4μ)(1 − r²/R²)Q = πR⁴G/(8μ)
Slip-velocity form (Eqs. 3 and 5)u(r) = (R²G/4μ)(1 − r²/R²) + usQ = πR⁴G/(8μ) + πR²us

The slip velocity us is the liquid velocity at the boundary, taken from the molecular simulation. The pressure gradient is G = ΔP/L, with ΔP the difference between the bulk regions of the two reservoirs and L the tube length. That is the source paper’s convention; it assigns the whole pressure drop to the tube.

Where the liquid ends

The source paper compares two definitions of the radius: half the tube diameter D between carbon centres (wall position) and half the diameter D′ of the first density peak of the water. Each has its own slip velocity. Neither is asserted here to be the correct one. The switch “Compare boundary definitions” shows how far the model moves between them; that band is a sensitivity to a definition, not an uncertainty.

Viscosity

Three values from the source paper (Fig. 8c): the interfacial viscosity from non-equilibrium molecular dynamics (local shear stress over shear rate), the Green–Kubo viscosity from equilibrium molecular dynamics, and the experimental viscosity of water. The source also plots a bulk-liquid viscosity, which lies between the last two for this tube and is not offered separately. The model uses one viscosity across the whole section.

Equivalent slip length

The Navier condition (Eq. 8) relates the slip velocity to the wall shear rate, us = Ls |du/dr| at r = R, which gives Ls = 2μus/(GR). The page reports this length for information. The source paper’s own slip-length forms (Eqs. 4 and 6) are not enabled for this case; the case sheet says why.

Entrance-resistance sensitivity

The source paper’s Eq. 7 puts a resistance for the two ends in series with the tube: Q = ΔP / (Rends + Rtube), with Rends = cμ/R³ and Rtube = 8μL / [π(R⁴ + 4R³Ls)]. It does not give a value for c. The sensitivity uses c = 3, Sampson’s result for a circular opening in a thin plane wall without slip, both sides together [1], and the equivalent slip length above. The profile is computed with the interior pressure drop only, ΔP Rtube/(Rends + Rtube), so no loss is counted twice.

Because it changes the model, this is reported as a sensitivity, apart from the reproduction of the source curves. The value of c for the geometry of this simulation is not known.

Uncertainty

Every input was read from a published figure and carries an extraction uncertainty of 2.5 pixels on the figure axis, taken as one standard uncertainty. The uncertainty of the model flow rate propagates those of the pressure drop, the viscosity, the slip velocity and, at D′, the boundary diameter to first order. It says how well the figures could be read. It is not a statistical uncertainty of the simulation.

  1. Sampson, R. A. (1891). On Stokes’s current function. Phil. Trans. R. Soc. A 182, 449.
Limitations
  • One tube, one pressure drop, one temperature, one published simulation. Nothing here says how the result changes with diameter, drive or temperature.
  • The inputs were read from figures, not taken from the simulation files. Each carries an extraction uncertainty; the case sheet lists the items that the original numbers would settle.
  • The model is a continuum description with one viscosity and a sharp boundary. For water in a tube of this size both are definitions with more than one reasonable choice, which is why the page offers three viscosities and two boundary positions and asserts none of them.
  • The slip velocity was measured in the driven run that also supplies the reference, so the comparison cannot count as a prediction.
  • End resistance is not part of the source’s Eqs. 3 and 5. The sensitivity uses an assumed coefficient.
  • The open items of the case sheet (tube length, slip velocity at the wall position, flow definition and others) are unresolved.
  • The page was checked in headless Chromium only; Safari, Firefox, real phones and screen readers were not tested.
