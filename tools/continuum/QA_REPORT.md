## Molecular calibration pilot (functionality only, not a measurement)

Functionality only; no number here enters the lab. LAMMPS (22 Jul 2025 - Update 4) on one core. The builder reproduces the same data file (SHA-256 59315c32…) from the default seed: 4661 atoms (842 fixed carbons, 1273 SPC/E waters), cell 2.95 nm × 2.98 nm × 7.10 nm. Speed 2.73–3.06 ns/day on one core of a shared machine, so the campaign (480 ns of production) needs about 157–176 single-core days; its 24 runs are independent.
